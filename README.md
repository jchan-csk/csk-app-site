# csk-app-site

Public support and privacy pages for CSK International apps, served by GitHub Pages at https://jchan-csk.github.io/csk-app-site/.

One folder per app, each with `index.md` (support) and `privacy.md`. App code lives in its own private repo; the source for Hockey Logger's pages is `docs/` in `jchan-csk/hockey_logger`, so edit there and copy here.
